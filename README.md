# TeasyCard

A responsive HTML/CSS/JavaScript tourism website concept focused on Tawau, Sabah.

## Included
- Home page
- City attractions
- Nature & adventure
- Restaurants & cafés
- Car rental
- Hotels & homestays
- Travel information
- Leaflet interactive map
- Colour-coded map markers
- Search and category filters
- Placeholder images

## Marker colours
- Purple = City attractions
- Green = Nature
- Red = Restaurants / cafés
- Blue = Car rental
- Orange = Accommodation

## How to change images
Open the relevant file inside `data/` and replace the `image:` URL.

Example:
`image:"https://placehold.co/1200x675/..."`

Replace it with your own image URL:
`image:"images/restaurants/thai-spoon.jpg"`

Then create the matching folders/files if you are hosting locally.

## Important
The sample business information is starter data. Verify current ratings, reviews, menus, prices, opening hours, addresses and contact details before publishing as factual information.
